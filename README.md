# 澜阅

> 让长帖自然流动。

澜阅是面向 [LINUX DO](https://linux.do/) 长帖阅读场景的轻量阅读器。它以稳定的时间基准驱动页面滚动，提前衔接 Discourse 分批加载的楼层，并通过小尺寸、可拖动、可收起的阅读控制台展示进度、用时和本次阅读行程。

脚本提供“当前帖、自动帖、连续读”三种模式。连续阅读会从用户打开的列表建立滑动队列，读完后回到原列表补充新帖，在同一标签页逐篇阅读；它不会点赞、回复、收藏、模拟随机点击，也不会伪造或直接提交阅读统计。

## 主要特性

- **三种阅读模式**：既可只读当前帖子，也可在手动打开帖子后自动开始，或从列表建立有限连续阅读队列。
- **自然的平均阅读节奏**：按 `px/s`（每秒像素）设置平均速度，并在 ±12% 范围内缓慢变化；不受 60Hz、120Hz 等屏幕刷新率或页面缩放比例影响。
- **提前衔接后续楼层**：三种模式都会提前触发 Discourse 自身的隐藏加载哨兵；站点仍按自己的批次加载，但阅读时能保持几批内容在前方缓冲。只有确认原生正文流已到末楼后才会结束。
- **按楼层规划连续阅读**：连续读会综合帖子进度、时间线、已加载楼层和 Discourse 预载数据估算楼层总数，为每篇设置 30 秒至 10 分钟的最低有效阅读时长；发现后续楼层时只会延长计划。
- **离屏前阅读确认**：未读蓝点即将离开视口时，以同屏楼层为一组短暂确认；蓝点在正常滚动中消失便无需额外停留。
- **有界的记录恢复**：连续蓝点未消失时先用 `1px` 真实微滚动让站点重新核对可见楼层；仍连续失败时只重载当前帖的当前楼层一次并自动恢复。重载后仍未确认则停在本帖，不会跳过问题楼层或切换到下一帖。
- **识别帖子内定位**：Discourse 自动更新当前楼层地址时保持阅读，不会把同一帖子内的定位变化误判成换页。
- **阅读节奏预设**：提供“沉浸、标准、速览”三档预设，也可使用滑块精细调节。
- **持续补充的连续读**：默认保持 10 篇待读帖，可在 1–20 篇间调整；剩余约 2 篇时回原列表补满。本轮总上限默认 100 篇，可调 10–200 篇；列表无新帖或达到上限后结束。
- **手动操作保护**：可选在滚轮、触摸或翻页键接管页面时暂停；默认关闭，并忽略刚启动时残留的触控板惯性输入。
- **后台暂停**：可选在切换标签页时暂停，返回原帖子后自动继续；默认关闭，避免自动阅读无故中断。
- **本次阅读统计**：显示页面进度、有效运行时间和滚动距离。
- **站点原生主题**：采用 `336px` 小尺寸双栏布局，并读取 Discourse 的背景、文字、边线与强调色令牌；切换亮色、暗色或站点自定义配色时自动同步。
- **可操作的收起胶囊**：收起后显示 `148 × 48px` 快捷胶囊，主区可直接开始、暂停或继续阅读，右侧独立按钮展开完整设置；进度环、状态图标和中文说明持续反馈当前状态。
- **主题水纹材质**：胶囊使用轻量 WebGL 着色器绘制低饱和水纹，颜色随网页主题与阅读状态变化；限制在约 30fps，后台、展开态和“减少动态效果”环境会停止动画，WebGL 不可用时自动使用 CSS 降级效果。
- **稳定的位置系统**：展开态保留安全边距和贴边，收起态不为完整面板预留活动区域；位置计算不受缩放动画、后台降帧或减少动态效果影响。
- **最小权限**：仅匹配 LINUX DO 帖子及指定列表页面，使用 `@grant none`，没有跨域访问和第三方依赖。

## 安装

### 一键安装

安装 Tampermonkey、Violentmonkey 或 ScriptCat 后，打开下面的脚本地址：

[安装澜阅](https://raw.githubusercontent.com/LaminaLumen/Lanyue/main/Lanyue.user.js)

用户脚本管理器会自动显示安装确认页。安装完成后，刷新任意 LINUX DO 帖子页，或新帖、未读、未看、最新列表即可使用。

澜阅以新的脚本名称和发布文件提供。若此前安装过 AutoReadingForLD，请先停用或卸载旧脚本，再安装澜阅，避免两个脚本同时运行。

### 手动安装

1. 打开用户脚本管理器，新建脚本。
2. 复制 [`Lanyue.user.js`](./Lanyue.user.js) 的完整内容。
3. 粘贴并保存。
4. 打开或刷新帖子页，或 `/new`、`/unread`、`/unseen`、`/latest` 列表页。

## 使用方法

控制台默认以右侧快捷胶囊出现，当前是否滚动、暂停或完成无需展开即可确认。点击胶囊主区即可开始、暂停或继续阅读，点击右侧参数按钮才会展开完整设置；拖动主区可以将入口移动到窗口任意位置。面板会根据入口所在象限向左或向右、向上或向下展开。展开后可进一步选择阅读模式：

| 模式 | 适用场景 | 行为 |
| --- | --- | --- |
| 当前帖 | 只阅读眼前这篇 | 手动点击开始，确认到达末尾后停止 |
| 自动帖 | 由用户自己选择帖子 | 手动打开帖子后自动开始，到达末尾后停止 |
| 连续读 | 持续阅读列表中的新帖 | 在 `/new`、`/unread`、`/unseen` 或 `/latest` 建立滑动队列，读完后补充，直到列表耗尽或达到本轮上限 |

通用操作：

1. 点击状态区下方的主按钮开始或暂停；在列表页的“连续读”模式下，该按钮用于建立或停止队列。
2. 拖动平均速度滑块，或选择“沉浸、标准、速览”预设。
3. 在设置区按需启用后台暂停、手动操作暂停；两项默认关闭。连续读可分别设置队列容量和本轮总篇数上限。
4. 拖动顶部点阵或标题栏可移动控制台；展开态靠近窗口边缘时会自动贴边。
5. 点击右上角减号将控制台收起。收起后可直接点按主区控制阅读，右侧参数按钮负责再次展开；入口不会受完整面板尺寸限制，可拖到窗口任意边角。

连续阅读只收集原列表中带站点未看或未读标记、且从未访问过的帖子；已读旧帖即使后来出现新回复，也不会加入队列。本轮收集过的话题不会重复入队。队列剩余约 2 篇时，会回到原列表，通过站点自身的列表加载机制寻找后续新帖，补到设定容量后继续；每篇之间只在页面可见时冷却 8 秒。达到本轮总上限、列表没有更多新帖或列表无法继续加载时，读完手头篇目后结束。运行中修改两项篇数设置，从下一轮开始生效。整个过程保持同一标签页；偏离原列表、正文加载超时、阅读记录持续未确认或手动点击“停止连续阅读”时会停止。

每篇进入连续读后会按楼层总数安排最低有效阅读时间。速度滑块仍表示期望平均速度：未加载完的长帖按设定速度滚动；确认加载到末楼后，若高速档会过早读完，才根据剩余距离与时间收敛速度。提前到达真正末尾时会继续显示剩余时间，暂停和后台冻结时间不计入连续阅读计划。

阅读记录由 LINUX DO / Discourse 自身根据页面是否位于前台、楼层是否进入视口及实际停留时间判定。澜阅会读取帖子日期旁的本地已读/未读 DOM 状态，但不直接调用、伪造或代理阅读上报。蓝点即将离开视口仍未消失时，脚本才会短暂停留；到达真正末尾后还会等待记录稳定，确认或执行有界恢复后才结束。若希望站点正常记录阅读，请让帖子标签页保持可见；浏览器在后台冻结页面时无法保证继续滚动或计时。

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt + S` | 开始或暂停阅读 |
| `Alt + ↑` | 提高滚动速度 |
| `Alt + ↓` | 降低滚动速度 |
| `Alt + M` | 展开或最小化控制台 |

在输入框、回复编辑器或其他可编辑区域中，快捷键不会触发。

## 隐私与安全

- 设置只保存在 `linux.do` 域下的浏览器本地存储中。
- 单次重载恢复标记只保存在当前标签页的会话存储中，5 分钟后失效，不包含账号信息或帖子内容。
- 脚本不读取 Cookie、Token、账号资料或帖子正文。
- 脚本不向任何第三方服务器发送请求。
- 脚本不调用点赞、回复、书签或阅读上报接口。
- 连续队列与设置只保存在本站本地存储；恢复时会再次校验地址必须属于当前站点。
- 脚本仅读取当前页面的未读标记，执行原生滚动，并在有界恢复时最多重载当前帖一次；网站如何记录浏览行为仍由 LINUX DO 自身决定。

请按照社区规则和正常阅读节奏使用。项目不提供风控规避、随机点击、自动互动、无限遍历或信任等级操纵能力。

## 开发与验证

项目不需要构建，也没有运行时依赖。使用 Node.js 18 或更高版本执行：

```powershell
npm run check
```

检查内容包括 JavaScript 语法、元数据完整性、版本一致性、权限范围以及高风险 API 的意外引入。

详细说明见 [`docs/DEVELOPMENT.md`](./docs/DEVELOPMENT.md)。

## 设计原则

控制台使用 LINUX DO / Discourse 当前主题的背景、文字、边线和强调色，在不脱离网页视觉语境的前提下保留克制的阅读仪器质感。界面布局、状态语义、动效和移动端约束见 [`docs/DESIGN.md`](./docs/DESIGN.md)。
