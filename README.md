# AutoReadingForLD

AutoReadingForLD 是面向 [LINUX DO](https://linux.do/) 长帖阅读场景的轻量用户脚本。它以稳定的时间基准驱动页面滚动，在帖子触底时等待 Discourse 懒加载，并通过一个小尺寸、可拖动、可收起的阅读控制台展示进度、用时和本次阅读行程。

脚本提供“当前帖、自动帖、连续读”三种模式。连续阅读只会从用户打开的列表中建立有上限的队列，在同一标签页逐篇阅读，并在每篇之间执行前台冷却；它不会点赞、回复、收藏、模拟随机点击，也不会伪造或直接提交阅读统计。

## 主要特性

- **三种阅读模式**：既可只读当前帖子，也可在手动打开帖子后自动开始，或从列表建立有限连续阅读队列。
- **自然的平均阅读节奏**：按 `px/s`（每秒像素）设置平均速度，并在 ±12% 范围内缓慢变化；不受 60Hz、120Hz 等屏幕刷新率影响。
- **适配 Discourse 懒加载**：接近底部后持续等待后续楼层，只有页面高度稳定超过设定时间才结束。
- **阅读节奏预设**：提供“沉浸、标准、速览”三档预设，也可使用滑块精细调节。
- **有界连续阅读**：默认最多 8 篇，可在 1–20 篇之间调整；每篇结束后只在页面可见时冷却 8 秒，再进入下一篇。
- **手动操作保护**：使用滚轮、触摸或翻页键时可自动暂停，避免脚本和用户争抢页面控制权。
- **后台暂停**：切换到其他标签页时可自动暂停。
- **本次阅读统计**：显示页面进度、有效运行时间和滚动距离。
- **书页边注式控制台**：采用 `336px` 小尺寸双栏布局、全中文信息层级与统一线性图标，支持亮色/暗色主题。
- **自由收起入口**：收起后只保留 `46px` 书本入口、页面进度环和状态点，可移动到整个视口范围；再次展开时会按所在象限自动向内伸展。
- **稳定的位置系统**：展开态保留安全边距和贴边，收起态不为完整面板预留活动区域；位置计算不受缩放动画、后台降帧或减少动态效果影响。
- **最小权限**：仅匹配 LINUX DO 帖子及指定列表页面，使用 `@grant none`，没有跨域访问和第三方依赖。

## 安装

### 一键安装

安装 Tampermonkey、Violentmonkey 或 ScriptCat 后，打开下面的脚本地址：

[安装 AutoReadingForLD](https://raw.githubusercontent.com/LaminaLumen/AutoReadingForLD/main/AutoReadingForLD.user.js)

用户脚本管理器会自动显示安装确认页。安装完成后，刷新任意 LINUX DO 帖子页，或新帖、未读、未看、最新列表即可使用。

### 手动安装

1. 打开用户脚本管理器，新建脚本。
2. 复制 [`AutoReadingForLD.user.js`](./AutoReadingForLD.user.js) 的完整内容。
3. 粘贴并保存。
4. 打开或刷新帖子页，或 `/new`、`/unread`、`/unseen`、`/latest` 列表页。

## 使用方法

控制台默认以右侧小书本入口出现。入口可在整个窗口内自由拖动；点击后，面板会根据入口所在象限向左或向右、向上或向下展开。展开后先选择阅读模式：

| 模式 | 适用场景 | 行为 |
| --- | --- | --- |
| 当前帖 | 只阅读眼前这篇 | 手动点击开始，确认到达末尾后停止 |
| 自动帖 | 由用户自己选择帖子 | 手动打开帖子后自动开始，到达末尾后停止 |
| 连续读 | 阅读列表中的多篇内容 | 在 `/new`、`/unread`、`/unseen` 或 `/latest` 建立有限队列，同一标签页逐篇阅读 |

通用操作：

1. 点击状态区下方的主按钮开始或暂停；在列表页的“连续读”模式下，该按钮用于建立或停止队列。
2. 拖动平均速度滑块，或选择“沉浸、标准、速览”预设。
3. 在设置区选择是否启用后台暂停、手动操作暂停；连续阅读还可设置单次队列上限。
4. 拖动顶部点阵或标题栏可移动控制台；展开态靠近窗口边缘时会自动贴边。
5. 点击右上角减号将控制台收起。收起入口不会受完整面板尺寸限制，可拖到窗口任意边角。

连续阅读只收集当前列表中已经加载、符合条件的帖子，不会无限翻页。队列在同一标签页运行，偏离当前队列、正文加载超时或手动点击“停止连续阅读”时会停止；全部完成后会返回建立队列的列表页。

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt + S` | 开始或暂停阅读 |
| `Alt + ↑` | 提高滚动速度 |
| `Alt + ↓` | 降低滚动速度 |
| `Alt + M` | 展开或最小化控制台 |

在输入框、回复编辑器或其他可编辑区域中，快捷键不会触发。

## 隐私与安全

- 设置只保存在 `linux.do` 域下的浏览器本地存储中。
- 脚本不读取 Cookie、Token、账号资料或帖子正文。
- 脚本不向任何第三方服务器发送请求。
- 脚本不调用点赞、回复、书签或阅读上报接口。
- 连续队列与设置只保存在本站本地存储；恢复时会再次校验地址必须属于当前站点。
- 脚本仅执行浏览器原生页面滚动；网站如何记录页面浏览行为由 LINUX DO 自身决定。

请按照社区规则和正常阅读节奏使用。项目不提供风控规避、随机点击、自动互动、无限遍历或信任等级操纵能力。

## 开发与验证

项目不需要构建，也没有运行时依赖。使用 Node.js 18 或更高版本执行：

```powershell
npm run check
```

检查内容包括 JavaScript 语法、元数据完整性、版本一致性、权限范围以及高风险 API 的意外引入。

详细说明见 [`docs/DEVELOPMENT.md`](./docs/DEVELOPMENT.md)。

## 设计原则

控制台采用暖纸白、深林绿与低饱和赤陶色，避免高饱和渐变、大面积毛玻璃和层层卡片。界面布局、状态颜色、动效和移动端约束见 [`docs/DESIGN.md`](./docs/DESIGN.md)。
