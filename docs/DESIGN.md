# 控制台设计与交互规范

## 产品定位

AutoReadingForLD 的控制台是一件附着在帖子边缘的“阅读仪器”，不是通用管理后台。它应在长时间阅读中保持克制，在需要操作时又能迅速说明当前模式、阅读状态和下一步动作。

设计关键词：**书页边注、暖纸、深林、赤陶、安静、可信赖**。

## 形态与尺寸

### 展开态

- 基准宽度为 `336px`，常规内容高度约 `475px`；高度不足时限制为 `calc(100vh - 24px)`。
- 使用 `70px + 自适应内容区` 的双栏结构。左栏是阅读模式轨，右栏承载状态、主操作和参数。
- 外框使用 `14px` 圆角、细描边和两级柔和阴影，形成轻薄纸张感，不使用大面积毛玻璃或高饱和渐变。
- 展开态与视口保持至少 `12px` 安全边距；靠近边缘 `24px` 内释放拖动时自动贴边。

### 收起态

- 仅保留 `46 × 46px` 的书本入口，不继续占用展开面板的宽高。
- 外圈显示当前页面阅读进度，右下角状态点表达待机、运行、暂停或完成。
- 收起入口可在完整视口范围内移动，边距为 `0`；约束只保证入口本身不离开屏幕。

## 信息架构

左侧模式轨从上到下依次为：

1. 点阵拖动把手；
2. 当前帖；
3. 自动帖；
4. 连续读；
5. 快捷键提示。

右侧内容区按操作频率排列：

1. 项目名称、版本与收起按钮；
2. 当前状态、说明、队列摘要和开始/暂停/停止主操作；
3. 平均阅读速度与滑块；
4. 阅读参数；
5. 本次统计；
6. 阅读保护；
7. 自然变速说明与位置复位。

“阅读参数”“本次统计”“阅读保护”互斥展开，避免低频内容同时撑大面板。

## 自适应展开规则

收起入口以自身中心点判断所在象限，面板始终优先向视口内部生长：

| 入口位置 | 面板展开方向 | 稳定锚点 |
| --- | --- | --- |
| 左上 | 向右、向下 | 左上角 |
| 右上 | 向左、向下 | 右上角 |
| 左下 | 向右、向上 | 左下角 |
| 右下 | 向左、向上 | 右下角 |

当入口贴在视口极限位置时，展开态会优先满足 `12px` 安全边距，因此允许锚点向内移动最多一个安全边距。其他位置切换展开/收起时，对应角应保持不动。

定位计算使用宿主元素的布局坐标与实际布局尺寸，不读取缩放动画中的视觉矩形。这样可以避免后台标签页降帧、浏览器节流或 `prefers-reduced-motion` 导致位置漂移。展开动画的原点和轻微位移方向与当前锚点保持一致，动画只负责视觉反馈，不参与位置计算。

## 视觉语言

### 色彩

- `surface`：带少量灰度的暖纸白；暗色主题使用低亮度墨绿色，而不是纯黑。
- `ink`：略带绿色倾向的炭黑，用于标题、正文和关键读数。
- `forest`：深林绿，用于主操作和稳定状态，表达安静、可靠。
- `terracotta`：低饱和赤陶色，只用于进度、选中标记和小面积状态提示。
- `rail-selected`：灰鼠尾草色，用于模式选中和参数区域，不使用荧光色。

所有强调色均限制在较小面积。亮色和暗色主题保持相同语义，不做简单反相。

### 字体

- 状态标题使用本地衬线字体，保留阅读器气质。
- 参数与版本信息使用本地等宽字体，形成仪器读数感。
- 操作与说明使用系统中文界面字体，保证小字号清晰度。
- 项目不加载远程字体。

### 图标

- 全部功能图标来自 Phosphor Icons 2.1.1 Regular，保持相同线性语言和笔画重量。
- 图标只在能缩短识别时间时使用，不用装饰性图标填满界面。
- 当前模式使用赤陶色图标和左侧细线；未选模式使用中性灰绿色。
- 主按钮图标随状态切换为播放、暂停或停止；收起入口使用打开的书本图标。
- SVG 路径直接内嵌并继承文字颜色，不运行时请求远程资源。

## 状态设计

| 状态 | 语义 | 视觉反馈 |
| --- | --- | --- |
| `idle` | 尚未开始 | 深林绿状态点与“待机”标签 |
| `running` | 正常滚动 | 赤陶状态点和轻微呼吸动效 |
| `loading` | 新楼层已出现 | 赤陶提示，说明正在衔接内容 |
| `waiting` | 位于底部等待懒加载 | 赤陶提示并显示剩余秒数 |
| `queue` | 队列已建立或正在准备正文 | 深林绿状态并显示队列序号 |
| `cooldown` | 当前帖子完成，等待下一篇 | 赤陶状态并显示前台倒计时 |
| `paused` | 用户或规则触发暂停 | 中性色状态点 |
| `done` | 页面高度稳定，确认到底 | 深林绿完成状态 |

## 连续阅读约束

- 入口只在明确支持的列表页面工作，默认上限为 8 篇，可在 1–20 篇之间调整。
- 队列保持当前列表顺序，并在同一标签页导航，避免弹窗和多窗口失控。
- 每篇之间使用固定的 8 秒前台冷却；页面处于后台时倒计时暂停。
- 不提供随机点击、自动互动、隐藏行为或无限遍历；停止入口在队列运行期间始终可见。

## 响应式与可访问性

- 窗口宽度不超过 `390px` 时，面板宽度限制为 `min(330px, calc(100vw - 24px))`，模式轨缩为 `66px`。
- 窗口高度不足时，仅内容区滚动，模式轨、标题、收起入口和页脚保持可用。
- 所有操作使用原生 `button`、`input`、`label` 和 `details/summary`。
- 关键按钮提供明确的 `aria-label`，状态区域使用 `role="status"` 与 `aria-live="polite"`。
- 键盘焦点使用高对比轮廓，不依赖颜色表达选择。
- 支持 `prefers-reduced-motion`，将非必要动画缩短到近乎静止。
- 图标 SVG 标记为装饰内容，控件名称由中文文本或可访问名称提供。

## 样式隔离

控制台挂载在 Shadow DOM 中，避免 LINUX DO / Discourse 主题样式覆盖组件，也避免脚本样式污染论坛页面。主题明暗通过页面背景亮度和站点主题标识推断，只同步明暗语义，不复制站点内部组件实现。
