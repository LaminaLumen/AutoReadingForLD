# 控制台设计与交互规范

## 产品定位

澜阅的控制台是一件附着在帖子边缘的“阅读仪器”，不是通用管理后台。它应在长时间阅读中保持克制，在需要操作时又能迅速说明当前模式、阅读状态和下一步动作。

设计关键词：**书页边注、水波线条、站点原生、状态可读、安静、可信赖**。

“澜阅”以简化的水波线条作为品牌识别元素，表达文字连续流动的阅读体验。品牌图形只出现在标题区和自然变速说明中，不与状态图标争夺注意力。

## 形态与尺寸

### 展开态

- 基准宽度为 `336px`，常规内容高度约 `475px`；高度不足时限制为 `calc(100vh - 24px)`。
- 使用 `70px + 自适应内容区` 的双栏结构。左栏是阅读模式轨，右栏承载状态、主操作和参数。
- 外框使用 `16px` 圆角、细描边和两级柔和阴影，形成轻薄纸张感；背景、文字、边线和强调色均跟随当前网页主题。
- 展开态与视口保持至少 `12px` 安全边距；靠近边缘 `24px` 内释放拖动时自动贴边。

### 收起态

- 使用 `148 × 48px` 的紧凑快捷胶囊，不继续占用展开面板的宽高。
- 胶囊由主操作区和独立设置入口组成：点击主区直接开始、暂停或继续，拖动主区移动位置；点击右侧参数按钮才展开完整控制台。
- 左侧圆形进度环显示页面阅读进度，并根据状态切换播放、波形、队列、暂停、等待或完成图标。
- 中部两行文字直接说明当前状态和可执行动作；阅读中显示平均速度，等待、暂停和完成显示对应语义，不能只依赖颜色或微小状态点。
- 背景水纹由内嵌 WebGL 着色器绘制，只使用网页主题色和当前状态色。动画限制在约 30fps，仅在收起且阅读活跃或悬停时运行；后台、展开态和“减少动态效果”环境只保留静态帧，WebGL 不可用时回退到 CSS 渐变。
- 收起入口可在完整视口范围内移动，边距为 `0`；约束只保证入口本身不离开屏幕。

## 信息架构

左侧模式轨从上到下依次为：

1. 点阵拖动把手；
2. 当前帖；
3. 自动帖；
4. 连续读；
5. 快捷键提示。

右侧内容区按操作频率排列：

1. 澜阅品牌标识、产品副标题与收起按钮；
2. 当前状态、说明、队列摘要和开始/暂停/停止主操作；
3. 平均阅读速度与滑块；
4. 阅读参数；
5. 本次统计；
6. 阅读保护；
7. 自然变速说明与位置复位。

“阅读参数”“本次统计”“阅读保护”互斥展开，避免低频内容同时撑大面板。

## 自适应展开规则

收起入口以自身中心点判断所在象限，面板始终优先向视口内部生长：

| 入口位置 | 面板展开方向 | 稳定锚点 |
| --- | --- | --- |
| 左上 | 向右、向下 | 左上角 |
| 右上 | 向左、向下 | 右上角 |
| 左下 | 向右、向上 | 左下角 |
| 右下 | 向左、向上 | 右下角 |

当入口贴在视口极限位置时，展开态会优先满足 `12px` 安全边距，因此允许锚点向内移动最多一个安全边距。其他位置切换展开/收起时，对应角应保持不动。

定位计算使用宿主元素的布局坐标与实际布局尺寸，不读取缩放动画中的视觉矩形。这样可以避免后台标签页降帧、浏览器节流或 `prefers-reduced-motion` 导致位置漂移。展开动画的原点和轻微位移方向与当前锚点保持一致，动画只负责视觉反馈，不参与位置计算。

## 视觉语言

### 色彩

- 优先读取 Discourse 的 `--secondary`、`--primary`、`--primary-medium`、`--primary-low` 与 `--tertiary`，分别映射为组件背景、主要文字、次要文字、边线和强调色。
- 页面未提供完整令牌时，才回退到可见背景与正文颜色；透明背景必须跳过，不能把 `rgba(0, 0, 0, 0)` 误判成暗色。
- 面板层级色由站点背景与文字色少量混合得到，不维护一套与网页割裂的固定黑色或固定品牌色。
- 运行与队列使用站点强调色；暂停、等待和冷却使用低饱和警示色；完成使用稳定的绿色。所有状态同时提供图标与文字，不仅依赖颜色。

强调色限制在主操作、进度、选中标记和状态反馈等小面积区域。切换主题样式表、主题类名或系统配色时，组件应在同一页面内自动同步。

### 字体

- 状态标题使用本地衬线字体，保留阅读器气质。
- 参数读数使用本地等宽字体，形成仪器读数感。
- 操作与说明使用系统中文界面字体，保证小字号清晰度。
- 项目不加载远程字体。

### 图标

- 全部功能图标来自 Phosphor Icons 2.1.1 Regular，保持相同线性语言和笔画重量。
- 图标只在能缩短识别时间时使用，不用装饰性图标填满界面。
- 当前模式使用站点强调色图标和左侧细线；未选模式使用当前主题的次要文字色。
- 模式图标放入统一的圆角小容器，通过边线、底色和轻微位移表达悬停与选中，不依赖放大或高亮光效。
- 主按钮图标随状态切换为播放、暂停或停止；收起胶囊按状态切换播放、波形、书本、暂停、旋转等待和完成图标，右侧固定使用参数图标表示展开完整设置。
- SVG 路径直接内嵌并继承文字颜色，不运行时请求远程资源。

## 状态设计

| 状态 | 语义 | 视觉反馈 |
| --- | --- | --- |
| `idle` | 尚未开始 | 播放图标、“就绪”和“点按开始” |
| `running` | 正常滚动 | 波形图标、站点强调色呼吸反馈；连续读同时显示识别楼层数和最低时长 |
| `loading` | 新楼层已出现 | 旋转等待图标与“正在衔接楼层” |
| `waiting` | 位于底部等待懒加载或最低时长 | 旋转等待图标，以及懒加载倒计时或连续读剩余时间 |
| `queue` | 队列已建立或正在准备正文 | 书本图标和连续阅读篇数 |
| `cooldown` | 当前帖子完成，等待下一篇 | 旋转等待图标与“即将下一篇” |
| `paused` | 用户或规则触发暂停 | 暂停图标与“点按继续” |
| `done` | 页面高度稳定，确认到底 | 完成图标与“点按重读” |

## 连续阅读约束

- 入口只在明确支持的列表页面工作，默认上限为 8 篇，可在 1–20 篇之间调整。
- 队列保持当前列表顺序，并在同一标签页导航，避免弹窗和多窗口失控。
- 每篇按“15 秒基础时间 + 每层 3.2 秒”规划最低有效阅读时间，并限制在 30 秒至 10 分钟；楼层数来自帖子进度、时间线、已加载楼层和 Discourse 预载数据。
- 用户设置的平均速度是期望上限。若高速滚动会早于计划读完，则按剩余距离与剩余时间平滑限速；原速度更慢时不主动提速。
- 懒加载发现更多楼层时只延长、不缩短当前计划；暂停与页面不可见期间不消耗计划时间。只有最低时长和末尾稳定等待同时满足后，才进入篇间冷却。
- 每篇之间使用固定的 8 秒前台冷却；页面处于后台时倒计时暂停。
- 不提供随机点击、自动互动、隐藏行为或无限遍历；停止入口在队列运行期间始终可见。

## 响应式与可访问性

- 窗口宽度不超过 `390px` 时，面板宽度限制为 `min(330px, calc(100vw - 24px))`，模式轨缩为 `66px`。
- 窗口高度不足时，仅内容区滚动，模式轨、标题、收起入口和页脚保持可用。
- 所有操作使用原生 `button`、`input`、`label` 和 `details/summary`。
- 关键按钮提供明确的 `aria-label`，状态区域使用 `role="status"` 与 `aria-live="polite"`。
- 键盘焦点使用高对比轮廓，不依赖颜色表达选择。
- 支持 `prefers-reduced-motion`，将非必要动画缩短到近乎静止。
- 图标 SVG 标记为装饰内容，控件名称由中文文本或可访问名称提供。

## 样式隔离

控制台挂载在 Shadow DOM 中，避免 LINUX DO / Discourse 主题样式直接覆盖组件，也避免脚本样式污染论坛页面。主题同步读取 Discourse 色彩令牌，并监听页面主题属性、主题样式表和系统配色变化；若令牌缺失，再依据首个非透明页面背景判断明暗。
